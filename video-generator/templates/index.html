About
VideoForge AI generates 5-minute videos for ~₹100 using open-source Wan 2.2 model on rented cloud GPUs.
How it works: Rent cheapest GPU → Auto-install Wan 2.2 → Generate clips → Merge → Auto-stop GPU.
Cost: RTX 3090 @ ~₹13/hr, RTX 4090 @ ~₹34/hr. A 5-min video takes 2-6 hours depending on GPU.
Tech: Python + Flask + Vast.ai CLI + Paramiko SSH + FFmpeg.
